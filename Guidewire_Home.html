Glossário Consolidado

A

Agente SeguroPolicyCenter
No mercado norte-americano, intermediário vinculado a uma seguradora específica. No Brasil, a figura equivalente e regulamentada pela SUSEP é o corretor de seguros. Ver também Produtor.
Agent
Analytics Manager AnalyticsGWCP
Componente central do Predict que permite configurar, implantar e monitorar modelos preditivos dentro das aplicações InsuranceSuite. Suporta BYOM e oferece governança do ciclo de vida dos modelos.
Analytics Manager — model lifecycle management inside InsuranceSuite
Apólice SeguroPolicyCenter
Contrato formal de seguro entre o segurado e a seguradora, que define coberturas, condições, exclusões, prêmio e período de vigência.
Policy
Asteroid ArquiteturaGWCP
Tipo especial de planet para hospedar workloads que não são aplicações InsuranceSuite — como serviços conteinerizados de terceiros. Planets e asteroids podem compartilhar a mesma orbit.
Asteroid — specialized planet for non-InsuranceSuite workloads
Auditoria de Prêmio SeguroPolicyCenter
Revisão do prêmio cobrado com base nos valores reais de exposição (ex.: folha de pagamento) ao longo ou ao fim da vigência, para ajustar o prêmio estimado ao valor devido.
Premium Audit
Auditoria Final SeguroPolicyCenter
Auditoria executada pela seguradora ao término da vigência para determinar o custo real definitivo da apólice.
Final Audit

B

Bem Segurado SeguroPolicyCenter
Item concreto coberto pela apólice — veículo, imóvel, equipamento etc. No PolicyCenter, são adicionados durante o fluxo de proposta.
Risk Object
BillingCenter AplicaçãoGWCP
Aplicação de faturamento do InsuranceSuite. Centraliza o faturamento de prêmios e o atendimento de contas para apólices de seguro de danos. Gerencia faturas, pagamentos, delinquências, comissões e relatórios.
BillingCenter — premium billing and receivables management
BYOM — Bring Your Own Model AnalyticsGWCP
Capacidade do Predict / Analytics Manager que permite importar modelos de machine learning desenvolvidos externamente (Python, R etc.) e integrá-los ao fluxo de trabalho do InsuranceSuite.
BYOM — import externally built ML models into Analytics Manager

C

Cancelamento SeguroPolicyCenter
Encerramento antecipado da apólice antes do término da vigência, podendo ser iniciado pelo segurado ou pela seguradora.
Cancellation
CI/CD Dev & OpsGWCP
Práticas automatizadas de integração e entrega de software suportadas pelo GWCP por meio de pipelines (Bitbucket → TeamCity → Guidewire Cloud). Garante que apenas código testado promova-se até produção.
Continuous Integration / Continuous Delivery
CIF — Cloud Integration Framework IntegraçãoGWCP
Suite padronizada de tecnologias para integração entre o InsuranceSuite e sistemas externos. Inclui Cloud API (REST), REST API Client, App Events (assíncrono) e o Marketplace de integrações.
Cloud Integration Framework
ClaimCenter AplicaçãoGWCP
Aplicação de gestão de sinistros do InsuranceSuite. Cobre o ciclo completo: intake, atribuição, avaliação, reserva e pagamento, negociação e encerramento.
ClaimCenter — end-to-end claims management
Cloud API IntegraçãoGWCP
APIs REST expostas pelas aplicações InsuranceSuite no GWCP que permitem que sistemas externos acessem e manipulem dados de apólices, sinistros e faturamento de forma padronizada.
Cloud API — REST APIs exposed by InsuranceSuite
Cloud Data Access (CDA) Dev & OpsGWCP
Conectores que permitem acesso a dados do InsuranceSuite a partir de ferramentas externas de analytics ou relatórios. O número de conectores varia conforme a orbit do planet.
CDA — Cloud Data Access connectors
Cobertura SeguroPolicyCenter
Proteção contratual contra um risco específico. Cada bem segurado pode ter múltiplas coberturas associadas.
Coverage
Condição de Cobertura SeguroPolicyCenter
Parâmetros que definem os limites e termos de uma cobertura, como limite máximo de indenização e franquia.
Coverage Term
Cotação SeguroPolicyCenter
Estimativa de prêmio gerada pelo PolicyCenter após calcular o risco com base nas informações da proposta.
Quote

D

Data Platform AnalyticsGWCP
Componente do GWCP que consolida dados das aplicações InsuranceSuite em uma visão única e confiável. Serve de base para as soluções Explore e Predict.
Data Platform — unified data layer for InsuranceSuite analytics

E

Endosso SeguroPolicyCenter
Termo consagrado no mercado brasileiro para qualquer alteração formal em uma apólice vigente. No PolicyCenter, aparece como Policy Change — transação que modifica bens segurados, coberturas ou condições antes do vencimento.
Endorsement / Policy Change
Explore AnalyticsGWCP
Produto de Business Intelligence cloud-native do GWCP Analytics. Oferece Liveboards com dados quase em tempo real, busca em linguagem natural e alertas configuráveis. Não requer SQL ou ferramentas externas de BI.
Explore — cloud-native BI with Liveboards and natural-language search
Exclusão SeguroPolicyCenter
Risco, situação ou evento especificamente excluído da cobertura da apólice.
Exclusion

G

Galaxy ArquiteturaGWCP
A região geográfica da infraestrutura Guidewire Cloud. Cada galaxy representa uma região com seus próprios data centers. Uma isolation zone pode conter uma ou mais galaxies.
Galaxy — geographic infrastructure region
Guidewire Home AplicaçãoGWCP
Portal unificado e ponto de entrada do GWCP. Oferece SSO para todas as aplicações Guidewire, App Launcher, CI/CD Activity, notificações, busca global e acesso à documentação.
Guidewire Home — unified SSO portal for all GWCP apps
GWCP — Guidewire Cloud Platform ArquiteturaGWCP
Fundação SaaS cloud-native da Guidewire, construída sobre AWS com orquestração Kubernetes. Unifica apólices, faturamento, sinistros, analytics e engajamento digital para seguradoras de seguro de danos em uma plataforma continuamente atualizada, com modelo híbrido de tenancy.
Guidewire Cloud Platform — managed SaaS foundation for P&C insurance

I

InsuranceSuite ArquiteturaGWCP
Suite integrada de aplicações core de seguro de danos da Guidewire: PolicyCenter, BillingCenter e ClaimCenter. Opera em plataforma única com dados, workflows e APIs compartilhados, entregue no GWCP.
InsuranceSuite — integrated PolicyCenter + BillingCenter + ClaimCenter
Isolation Zone ArquiteturaGWCP
Grupo de galaxies que entrega funcionalidades do Cloud Platform dentro de um limite geográfico e regulatório específico. Garante soberania de dados — os dados não cruzam fronteiras entre isolation zones.
Isolation Zone — geographic and regulatory boundary grouping galaxies

J

Jutro Digital Platform AplicaçãoGWCP
Plataforma de desenvolvimento de interfaces digitais da Guidewire, baseada em React. Oferece sistema de design, componentes de UI, acesso a APIs e suporte a múltiplos idiomas. Usada para portais de autoatendimento de segurados, agentes e funcionários.
Jutro Digital Platform — React-based UI toolkit for digital portals

L

Linha de Negócio SeguroPolicyCenter
Categoria de produtos de seguro, como Auto Pessoal, Propriedade Comercial ou Workers' Compensation. Cada LOB tem seu próprio conjunto de coberturas e regras de tarifação.
Line of Business (LOB)
Liveboard AnalyticsGWCP
Dashboard interativo e em tempo real do Explore. Organizado por perfil de usuário, permite visualizar KPIs e métricas de negócio sem ferramentas externas de BI.
Liveboard — real-time role-based dashboard in Explore

M

Marketplace (Guidewire) IntegraçãoGWCP
Catálogo de integrações e aceleradores pré-construídos para o InsuranceSuite. Inclui conectores para sistemas externos, templates de integração e soluções de parceiros.
Guidewire Marketplace — catalog of prebuilt integrations and partner connectors

N

Não Renovação SeguroPolicyCenter
Decisão da seguradora de não estender a apólice ao término da vigência. A cobertura encerra na data de expiração.
Non-renewal

O

Orbit ArquiteturaGWCP
Etapa no ciclo de vida de desenvolvimento (SDLC) dentro de um star system. Cada orbit define o propósito de um planet: Dev, QA, UAT, PreProd, Prod. Apenas um planet pode operar na orbit de produção.
Orbit — SDLC stage within a star system

P

PAS — Policy Administration System AplicaçãoPolicyCenter
Sistema de Administração de Apólices — software que gerencia o ciclo de vida completo das apólices de seguro. O PolicyCenter é um PAS.
PAS — Policy Administration System
Período de Vigência SeguroPolicyCenter
Intervalo de tempo durante o qual a apólice está em vigor, com datas de início e término definidas.
Policy Term / Policy Period
Planet ArquiteturaGWCP
Ambiente onde o código é deployado e executado — ex.: aplicações InsuranceSuite. Um star system pode conter múltiplos planets em orbits diferentes, mas somente um pode ser Prod.
Planet — deployment environment within a star system
PolicyCenter AplicaçãoGWCP · PolicyCenter
Sistema de administração de apólices (PAS) do InsuranceSuite. Suporta o ciclo completo da apólice: design de produto, submissão, análise de risco, subscrição e rating, cotação/binding/emissão e renovação. Inclui o Automated Decision Platform (ADP).
PolicyCenter — Policy Administration System
Preempção AplicaçãoPolicyCenter
Situação em que uma nova transação de alteração é iniciada antes que a anterior seja vinculada. O PolicyCenter exige resolução antes de prosseguir.
Preemption
Predict AnalyticsGWCP
Produto de analytics preditivo do GWCP que usa o Analytics Manager para incorporar scores e recomendações de ML nas telas do InsuranceSuite. Suporta BYOM e governança de modelos em produção.
Predict — ML-powered predictive analytics embedded in InsuranceSuite
Prêmio SeguroPolicyCenter
Valor pago pelo segurado à seguradora pela cobertura contratada. Pode ser calculado com base em dados estimados (auditáveis) ou fixos.
Premium
Produtor SeguroPolicyCenter
Termo genérico do mercado norte-americano que agrupa agentes (vinculados a uma seguradora) e brokers (independentes). No Brasil, o equivalente regulamentado é o corretor de seguros — licenciado pela SUSEP para intermediar contratos. No PolicyCenter, o campo "Producer" corresponde ao corretor responsável pela apólice.
Producer
Proposta AplicaçãoPolicyCenter
Transação que inicia a criação de uma nova apólice no PolicyCenter, da qualificação do candidato à emissão do contrato.
Submission

R

Reabilitação SeguroPolicyCenter
Restauração de uma apólice cancelada ao estado anterior ao cancelamento. A data de reabilitação deve coincidir com a data efetiva do cancelamento para evitar lacuna de cobertura.
Reinstatement
Reescrição SeguroPolicyCenter
Criação de uma nova apólice a partir de uma existente, com novas datas e condições. Usada para alterações não permitidas em uma transação comum (ex.: mudança de produtor).
Rewrite
Relatório de Prêmio SeguroPolicyCenter
Relatório periódico preparado pelo segurado com dados reais de exposição (folha de pagamento, inventário etc.) para ajuste intermediário do prêmio durante a vigência.
Premium Report
Renovação SeguroPolicyCenter
Extensão da apólice para um novo período de vigência. O número da apólice é mantido; um novo número de vigência é acrescentado.
Renewal
Risco SeguroPolicyCenter
Possibilidade de perda ou dano coberto pela apólice. Na subscrição, é avaliado para determinar elegibilidade e prêmio.
Risk

S

Segurado SeguroPolicyCenter
Pessoa física ou jurídica cuja vida, saúde, propriedade ou responsabilidade é coberta pela apólice.
Insured / Policyholder
Seguradora SeguroPolicyCenter
Empresa que emite as apólices, assume os riscos e paga as indenizações em caso de sinistro.
Insurer / Carrier
Sinistro SeguroPolicyCenter
Solicitação formal do segurado à seguradora por indenização em função de um evento coberto pela apólice. No Guidewire, é gerenciado pelo ClaimCenter.
Claim
Ski Release Dev & OpsGWCP
Ciclo regular de atualização da plataforma Guidewire Cloud. As atualizações são entregues automaticamente, mantendo as aplicações core sempre na versão mais recente sem upgrades manuais.
Ski Release — Guidewire's regular automated platform update cycle
SSO — Single Sign-On Dev & OpsGWCP
Mecanismo de autenticação centralizado do Guidewire Home que permite ao usuário acessar todas as aplicações GWCP com um único login.
SSO — Single Sign-On via Guidewire Home
Star ArquiteturaGWCP
Unidade de negócio ou serviço compartilhado dentro de um tenant que se deseja gerenciar independentemente. Cada star pode conter até três star systems e é completamente separada das demais.
Star — independent business unit within a tenant
Star System ArquiteturaGWCP
Grupo de planets que compartilham serviços do Cloud Platform. Existem três classes: dev (Dev/QA/UAT), pre-prod (PreProd) e prod (Prod). Cada star system tem seu próprio banco de dados dedicado.
Star System — group of planets sharing Cloud Platform services
Subscrição SeguroPolicyCenter
Processo de avaliação e seleção de riscos para determinar se uma proposta é aceitável e a que preço. O subscritor analisa dados da proposta para tomar essa decisão.
Underwriting

T

Tarifação SeguroPolicyCenter
Processo de cálculo do prêmio com base nos fatores de risco da apólice, regras tarifárias e dados do segurado. O PolicyCenter possui motor de tarifação nativo.
Rating / Pricing
Tenant ArquiteturaGWCP
Representa a presença de uma empresa em uma isolation zone do Cloud Platform. Limitado a uma única isolation zone por requisitos de residência de dados. Tenants são completamente isolados — sem compartilhamento de dados ou workloads.
Tenant — company presence in one isolation zone

V

Vigência SeguroPolicyCenter
Período específico de cobertura de uma apólice, delimitado por data de início e data de término. Uma apólice renovada gera uma nova vigência.
Policy Term
